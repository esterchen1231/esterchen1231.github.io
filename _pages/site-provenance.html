Site provenance and attribution

This repository builds Ester Chen's personal website at https://esterchen1231.github.io/. It is maintained as a personal academic website, not as a general-purpose website template.

Ester Chen's original additions include the custom page arrangements, theme picker, publication presentation, experience grouping, gallery presentation, booking interface, personal writing, and original photographs. Please contact esterchen1@acm.org before reusing this personal content or visual identity.

This notice does not replace or revoke any existing license or claim exclusive ownership of upstream code or third-party material.

The source metadata and assets/site-provenance.json identify this website's origin and a reproducible snapshot of selected files. Source markers in the HTML and stylesheets help preserve attribution when either is copied. Inclusion of a file in the manifest identifies the snapshot; it does not mean that every part of that file was authored by Ester Chen. The SHA-256 hashes are content fingerprints, not digital signatures, proof of authorship, or a way to prevent copying.
