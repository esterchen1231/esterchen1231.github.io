# Project Instructions

## Calendar basis

- Use `_data/meeting_unavailability.yml` as the source-of-truth basis calendar for all scheduling and calendar-related work in this repository.
- Interpret all listed times in the file's `source_timezone` unless the user explicitly requests another timezone.
- Preserve existing calendar entries unless the user explicitly asks to change or remove them.
- Before making scheduling decisions, read the current file so that later updates are included.
